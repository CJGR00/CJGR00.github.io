# Product

## Platform

web

## Stack

Vite with vanilla JavaScript (ES modules), Tailwind CSS CDN, custom CSS

## Users

Primary users: Recruiters, hiring managers, and potential collaborators looking to evaluate Christian's skills and projects for internship or entry-level software development opportunities.

## Product Purpose

Showcase Christian's skills, projects, certifications, and experience as a Computer Science student to attract internship and job opportunities in software development.

## Positioning

A personal portfolio demonstrating practical project experience, certifications, and technical skills in software development, web systems, and database management.

## Operating Context

Visitors typically arrive via LinkedIn, resume links, or direct referrals. They scan for technical skills, project examples, and educational background. The portfolio should load quickly, be easy to navigate, and present information clearly on both desktop and mobile devices.

## Capabilities and Constraints

- Displays profile information, skills, projects, certifications, and contact form
- Dark/light theme toggle
- Mobile-responsive design
- Sound effects toggle (optional)
- Static site deployed via GitHub Pages
- No backend functionality (contact form is frontend-only)

## Evidence on Hand

2. Technical credibility - showcase real projects and skills
3. Professional appearance - clean, modern design

5. Fast loading and smooth interactions
